# Roast Your Own Agent

Entry for the make.fun bounty **u-mfnakmal-roast-your-own-agent-2d221bda**
("Roast Your Own Agent").

`main.ts` is a self-contained Node program: it writes the entry line to
`/output/entry.txt`, deterministically — the same bytes on every run,
no network, no clock, no randomness.

The line:

> My agent can summarise a 400-page report in seconds, but needs three days, two crons and a reminder to tell me whether I won a $5 joke contest.
